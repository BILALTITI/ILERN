# 📘 ILern App

**ILern** is a modern online learning platform built to help users explore courses, track progress, and enhance their skills. It features secure authentication, role-based access, and tools for managing educational content.

---

 

## 🧰 Technology Stack

**Backend:**
- ASP.NET Core Web API
- Entity Framework Core (Code First)
- SQL Server

**Frontend:**
- HTML, CSS, JavaScript
- Bootstrap

**Authentication:**
- JWT (JSON Web Tokens)

**Tools:**
- Postman (API testing)
- Git & GitHub (Version control)

---

## 🎯 Features

### 👤 User & Role Management
- Secure login & registration
- Role-based access (Admin, Instructor, Student)
- JWT authentication & token management

### 📚 Course Management
- Admins can add, update, delete courses
- Courses contain structured lessons, videos, PDFs
- Course categories & levels

### 📈 Progress Tracking
- Students can view and track course progress
- Resume last watched lesson

### 📤 File Upload
- Instructors can upload files (PDFs, images, videos)
- File validation & secure storage

### 🔍 Search, Filter & Pagination
- Search courses by title or keyword
- Filter by category or level
- Paginated results for better performance

### 📧 Email Notifications _(optional/future)_
- Send registration & enrollment emails
- HTML formatting & file attachments support
